# AWS Customer Data Pipeline

## Project Overview

This project demonstrates an AWS-based ETL pipeline that processes customer data from a CSV file stored in Amazon S3, transforms the data using AWS Glue, and loads the processed customer records into MongoDB.

## Architecture

CSV → Amazon S3 → AWS Glue Crawler → Glue Data Catalog → AWS Glue ETL → MongoDB

## Technologies

- Amazon S3
- AWS Glue
- AWS Glue Data Catalog
- PySpark
- MongoDB Atlas
- GitHub
